# Evan Kinsel portfolio

A buildless, single-page portfolio for GitHub Pages. The site uses standard HTML and CSS, plus a poster preview image stored beside `index.html`.

## Files

- `index.html` - page structure, styling, copy, and responsive layout
- `evan-kinsel-hbt-poster-preview.webp` - Morehouse laser research poster preview

## GitHub Pages

The portfolio is published from the `main` branch at the repository root. Its project-site URL is https://evankinsel.github.io/evan-kinsel-portfolio/.

## Content notes

The QuantCAD case study describes the engineering process and resume-level outcomes while omitting proprietary plots, dimensions, geometry, and internal data. No GPA or resume file is included.
